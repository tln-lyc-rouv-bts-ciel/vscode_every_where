Procédure pour créer et déployer clés privé/publique

  • voir sur Internet pour utiliser la commande ssh-keygen

Configuration pour utiliser l'agent Windows

ctrl + shift + P -> Remote-SSH: Add New Host...

Entrer raspberrypi.local

ctrl + shift + P -> Remote-SSH: Open SSH Configuration File... C:\Users\ardui.ssh\config

Modifier comme ci-dessous :
Host raspberrypi.local
  HostName raspberrypi.local
  User franck
  IdentityFile C:\Users\ardui\.ssh\id_ed25519-remote-ssh
  ForwardX11 yes
  ForwardX11Trusted yes

Configuration pour utiliser l'agent ssh de Msys2

  • dans une console Msys2
pacman -S openssh
  • ajouter dans le settings.json (par défaut VSCode utilise l'agent de Windows) :
{
"remote.SSH.path": "D:\\PortableApps\\VSCodeEveryWhere\\App\\msys64\\usr\\bin\\ssh.exe"
}
  • créer le fichier conf dans ~/.ssh/ et copier le texte suivant :
Host raspberrypi.local
  HostName raspberrypi.local
  User franck
  IdentityFile /home/ardui/.ssh/id_ed25519
  ForwardX11 no
  ForwardX11Trusted no
Host rpi5ha.local
  HostName rpi5ha.local
  User fr_electro
  IdentityFile /home/ardui/.ssh/id_ed25519
  ForwardX11 no
  ForwardX11Trusted no
