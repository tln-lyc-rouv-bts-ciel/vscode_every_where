Suite UwAmp (Windows Apache MySql Php)

  • Lien de téléchargement : UwAmp
  • Version portable dézippée dans :
VSCodeEveryWhere
│   ├── app

Espace de travail

VSCodeEveryWhere
├───App
│   ├───UwAmp
│   │   ├───www
│   │   │   └───php

Intégration du gestionnaire UwAmp dans VSCode

ctrl + shift + P -> User settings (JSON)

Ajouter dans le fichier settings.json les lignes suivantes :

{
    "terminal.integrated.profiles.windows": {
            "UwAmp": {
            "path": "cmd.exe",
            "args": [
                "/c",
                "D:\\PortableApps\\VSCodeEveryWhere\\App\\UwAmp\\UwAmp.exe"
            ]
        }
}

Ajout du chemin du processeur php pour l'analyse de scripts

ctrl + shift + P -> User settings (JSON)

Ajouter dans le fichier settings.json la ligne suivante :

{
    "php.validate.executablePath": "D:\\PortableApps\\VSCodeEveryWhere\\App\\UwAmp\\bin\\php\\php-5.5.15\\php.exe"
}

Ajout de php.exe et mysqlq.exe à la variable PATH de VSCodeEveryWhere

  • Dans le fichier VSCodePortable.ini :
; Override Windows "PATH"
PATH=%PAL:AppDir%\UwAmp\bin\php\php-5.5.15;%PAL:AppDir%\UwAmp\bin\database\mysql-5.6.20\bin;%PATH%
  • Vérification des chemins d'installation dans la CLI Windows :
> where php
D:\PortableApps\VSCodeEveryWhere\App\UwAmp\bin\php\php-5.5.15\php.exe
> where mysql
D:\PortableApps\VSCodeEveryWhere\App\UwAmp\bin\database\mysql-5.6.20\bin\mysql.exe
